## S2 correction

The inherited item builder extracted the first numeric token from each source answer. This incorrectly treated fractions, symbolic expressions and multiple values as scalar numerical keys. The legacy bank and its random baseline are preserved under `outputs/archive_pre_audit/` and are not analysed.

The corrected builder accepts only a complete decimal scalar (including percent magnitudes and unambiguous grouped thousands). Science items additionally require one exact numeric option match; this is checked without the 1% grading tolerance, which must not be used to select an answer key. Symbolic answer types are conservatively excluded rather than automatically converted. The complete exclusion log, including unavailable Vietnamese stems, is `outputs/hard_items_excluded.csv`.

Of 432 source records, 55 have no Vietnamese stem and 141 more fail these conservative answer checks. The retained set has 236 unique items and 383 presentations:

| Subject | Unique items | MCQ | Open |
|---|---:|---:|---:|
| Mathematics | 89 | 0 | 89 |
| Chemistry | 89 | 89 | 89 |
| Physics | 58 | 58 | 58 |

This is a scalar-answer subset, not a representative sample of all difficult items. Chemistry and physics source years are unavailable. Mathematics years have only 3–21 selected items each. The dataset provider reports that some stems were reformulated; results do not constitute an evaluation of unchanged complete official papers for S2.

The 147 retained science records also carry source image attachments. These include scans of the printed stem and options, and the inspected example includes a highlighted answer key. They are not supplied to the models. Attachment presence is not used as an indicator of figure dependence; that property has not been separately coded for S2.

Open responses require an explicit final `Đáp án:` line with a complete numeric scalar. A number in the reasoning, a fraction numerator or the first coordinate is not accepted. Correctness uses 1% relative tolerance plus 1e-6 absolute tolerance. The open-format system prompt requests a number instead of asserting that four options exist. The S2 budget is 900 output tokens; MCQ uses brief reasoning, and open responses request a decimal numerical answer. Truncation and parsing failures must be read alongside accuracy.

The random S2 baseline guesses a seeded letter for MCQ and returns the fixed value 1 for open items. It is only a pipeline control; it is not a meaningful random-guessing baseline for an unbounded numeric response space and is omitted from the S2 manuscript tables.

## Re-run on Windows

From the project root, after installing `requirements.txt` into `.venv` and pulling the exact Ollama tags:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File code/run_local.ps1 -Phase All
```

All LLM runs resume by item ID. Do not start two writers for the same run file. `-Phase C` checks exact coverage and stored grades, then regenerates CSV analyses, LaTeX tables, figures and numerical result paragraphs. For analyses requiring parquet, use local execution outside a restricted sandbox if its parquet thread pool hangs.

```powershell
Set-Location Paper2_LLM_VNHSGE
latexmk -lualatex -interaction=nonstopmode -halt-on-error main.tex
```

Numerical paragraphs are generated by `code/11_write_results_text.py` into `Paper2_LLM_VNHSGE/results_text/`. Interpretive prose and limitations are in `main.tex`. Do not edit numerical snippets independently of their CSV source; regeneration overwrites them.

Before submission, authors must supply author names, affiliations, corresponding email and repository URL, review the AI-use declaration, and review the final scientific text. No teacher-coding validation or Cohen's kappa has been fabricated. Text-only results cannot establish multimodal resilience, and robustness does not establish absence of training-data contamination.
