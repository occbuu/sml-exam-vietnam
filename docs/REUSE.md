# Reuse and attribution

This release contains research scripts, a draft manuscript, and aggregate results. An explicit licence for the authors' code/manuscript has not yet been selected; public visibility alone does not grant an unrestricted redistribution licence. The authors can add a suitable licence after establishing ownership and any institutional requirements.

External datasets and model weights are not included. Their licences and terms remain separate. Cite the relevant original sources listed in `data/README.md` and the manuscript bibliography when using them.

The manuscript is an anonymous draft; author names, affiliation, publication DOI and repository URL are not fabricated. Add verified author metadata and a citation file when those details are available. Do not cite this work as an accepted article without a verified publication record.
